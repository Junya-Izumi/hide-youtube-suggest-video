# hide-youtube-suggest-video
This Chrome extension hides suggested videos while watching YouTube.<br>
It is extremely lightweight. It works by simply applying `display: none;` to the target elements via CSS.<br>
[日本語のREADMEはこちら](./README.md)
## Motivation
I usually watch YouTube with a specific video or topic in mind. However, I often found myself mindlessly clicking on tempting suggested videos, wasting more time than I intended.<br>
I created this extension to prevent this waste of time.
## Installation
1. Clone this repository or download and unzip the ZIP file.
```
git clone https://github.com/Junya-Izumi/hide-youtube-suggest-video.git
```
2. Open `chrome://extensions` in Chrome
3. Turn on "Developer mode" in the top right corner of the screen.
4. Click "Load unpacked" and select this extension folder.
## Updating
1. Pull the latest version, or download and extract the ZIP file to replace the existing files.
2. Open `chrome://extensions` in Chrome
3. Reload "hide-youtube-suggest-video"
